## 二、主要功能

1. 首页推荐：景点轮播、快捷入口、按日期轮换的今日推荐，支持中英文切换。
2. AI 路线生成：按天数、兴趣、节奏、出行方式生成个性化行程，展示高德地图 polyline 和途经点时间轴。
3. 智慧游记：游记分页、搜索、发布、编辑、删除、AI 起草、图片上传、点赞、评论。
4. 用户与社交：注册/登录、JWT 鉴权、公开主页、关注/取关、粉丝/关注列表、站内通知。
5. AI 导游：多轮对话、SSE 流式输出、工具调用、确定性行程求解、方案卡片、确认后写入我的路线。
6. 个人中心：资料编辑、头像上传、收藏、统计、我的游记、中英切换。
7. 微信小程序端：首页、路线、地图、游记、AI 导游、个人中心、商家文案、菜单 OCR 翻译、知识库。
8. 运维能力：统一错误信封、分页、上传限制、限流、幂等确认、优雅停机、systemd/nginx 部署脚本。

## 三、技术特点

1. 大模型与确定性规划器分工：模型负责理解需求、挑选候选地点和解释方案；`internal/planner` 负责时间窗解析、全排列、交通耗时和评分，避免模型编造时间。
2. Agent 工具白名单：9 个工具固定注册，工具身份只来自 JWT 上下文；`submit_plan` 只接受本 run 的 `solutionId`，stops、时间、坐标由服务端填充。
3. SSE 流式交互：`snapshot`/`delta`/`thinking`/`tool_call`/`tool_result`/`plan`/`done`/`error` 事件，带单调 `seq`，支持断线快照恢复、取消、排队超时和慢客户端丢弃。
4. 双后端同契约：Go 生产后端与 Java 参考后端共用 `docs/api/openapi.yaml` 和同一个 MySQL schema，响应字段一致；生产只运行 Go。
5. 可降级的外部依赖：高德失败时退化为 haversine 直线估算并标记 `routeConfidence=ESTIMATED`；天气未配置时返回 `available:false`，提示词要求模型说“未查询到”。
